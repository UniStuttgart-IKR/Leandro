# Recorded ioctl coverage

- These catalogues, probe results and investigation notes are historical evidence.
- Entries describe the recorded driver/GPU/workload, not current compatibility.
- Reaching an ioctl or compiling its descriptor is weaker evidence than checking
  its returned bytes. Read each result's status and provenance.
- Old paths and commands refer to the original harness. Current automated matrix
  tooling lives in the optional Leandro-Test repository.
- Current policy: [driver versions](../docs/abi-versions.md) and
  [testing](../docs/TESTING.md).
