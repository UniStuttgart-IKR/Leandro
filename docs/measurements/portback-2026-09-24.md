# Port-back from Caraxes, 2026-09-24

Step L1 of the Caraxes repository split: the v1 and shared changes made in the Caraxes
fork after the fork point `e2f1aec` (tag `v1-fork-point`) come back to Leandro on the
branch `port/caraxes-2026-09`. Source: Caraxes tag `pre-split-2026-09-24` (`c38db11`).
Nothing here was run on a GPU or in a VM.

## Method

Each Caraxes commit was exported with `git format-patch -1`, limited to the v1 and shared
paths below, and applied onto `e2f1aec` with `git am -3 --keep-cr`. No Caraxes object
entered this repository. Author, author date and message of every ported commit are
byte-identical to the original (compared with `git log --format='%an|%ae|%aI|%B'`), and
every file each ported commit touches has the same blob id as in the original commit.
Messages of path-limited commits still describe the whole original commit; the parts
outside the listed paths stayed in Caraxes.

`--keep-cr` is required: the four `hypervisor-*.txt` logs of the vhost-user check contain
CRLF line endings, and plain `git am` strips the CR, which changes the recorded logs.
